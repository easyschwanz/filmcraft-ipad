# FilmCraft fürs iPad

Die Browser-Version von [FilmCraft](https://github.com/storytold/filmcraft) (Open-Source-Videoschnitt im Stil von Premiere Pro, MIT/Apache-2.0) mit zusätzlichem Premiere-Docking und Touch-Bedienung fürs iPad.

**Öffnen:** https://easyschwanz.github.io/filmcraft-ipad/ in Safari, dann Teilen → „Zum Home-Bildschirm“.

- Tippen = Klick, Ziehen = verschieben, gedrückt halten = Kontextmenü
- Zwei Finger = scrollen, Pinch = zoomen (Timeline, Monitor)
- Startet auf Touch-Geräten im Workspace „Tablet“

Die Medien bleiben auf dem Gerät; nichts wird hochgeladen.
